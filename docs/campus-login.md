## 使用

当前主流程见 [通行证与默认离线缓存](passport-login.md)：直接登录通行证，程序自动获取教务信息，不再先创建本地账号和另点首次同步。已有本浏览器会话默认显示缓存；服务重启后无需先连校园服务即可阅读资料。需要新数据时登录更新，失败时保留上次结果。旧资料从“旧版本地资料登录”进入，并可在设置中显式绑定通行证。

教务查询需要验证码时由本人填写，再继续未完成批次；不会自动识别验证码或重试密码。“断开并清除校园数据”删除当前资料账号的校园快照并清除内存会话；“清除我的全部资料”也覆盖校园数据。

教务网可能需要校园网或学校 VPN。当前接入本科教务网和 ETA 个人基本信息，不支持研究生教务系统、扫码登录、MFA 或其他未适配平台。密码加密已与校方公开浏览器脚本对照，支持单字节字符与长密码分块；含中文或其他多字节字符的密码暂时明确拒绝，避免错误编码造成登录失败。

## 数据与失败状态

基本信息按字段整合三个来源：已登录教务菜单发现的本人个人页、ETA 的 `userInfo` 表单，以及课表响应 `xsxx`。仅保留学号、姓名、学院、专业、班级和年级；部分字段可先显示，缺失值不从通行证别名、学号或课程推断。新 ETA 字段优先于同次教务字段；默认/当前课表补充缺失或未更新字段，历史课表只补空值。每个字段独立记录来源、固定页面地址、获取时间与 `stale`，避免本次只更新姓名却把旧学院标成新数据。基本信息失败不阻断成绩或课表；教务连接失败但 CAS 仍有效时，也会尝试 ETA。登录自动获取，课表批次续传不会重复请求个人信息。个人信息查询最多使用独立 18 秒预算，随后重新开始教务批次的 45 秒预算。协议依据见 [ETA 适配说明](eta-profile.md)。

课表保留课程、课程号、教师、地点、星期、节次、周次、季学期及查询参数。支持页面 `xnm` 的四位年份或相邻学年区间（如 `2026-2027`），支持数字 `xqm` 及 `1|秋`、`1|冬`、`2|春`、`2|夏`；查询保留原始值，展示用学年起始年份作标识。默认学期优先，成功空课表也保存。页面列表不可用时，先获取成绩，再结合成绩学年、已有课表和已返回年级构造有限探测范围；没有历史依据时尝试当前及前七学年，每年四季，查询真实教务接口。降级范围最多 180 项，不声称已覆盖所有开放学期；认证、验证码及传输失败仍暂停。某一学期非 JSON/协议异常时保留其缓存并继续其他学期，单条课程异常保留其他有效行和上次缺漏课程，明确标记不完整。日期展示按学校来源、同学期缓存、默认推算降级，详见 [学业界面说明](academic-ui.md)。

每次请求最多查询六个学期，保留 45 秒操作期限和请求间隔。页面自动串行续传成功的批次并显示已完成/总学期数；验证码、错误响应或超时暂停，可点击“继续同步全部学期”。续传会话仅存在于当前教务连接的内存中，服务重启或重新登录后需重新同步，已保存结果仍可查看。旧版单学期快照会保留并转为按学期记录，未更新的学期显示“上次数据”。

成绩保留原始成绩、学分与绩点文本，分页查询全部可见学期，最多 20 页 / 2000 条；缺页或重复分页显示“不完整”，不计算毕业资格或认定学分。成绩在同步开始时获取，课表续传不重复读取成绩。

各部分独立记录获取时间。一次同步可以部分成功：失败部分保留上次数据并标记未更新，成功部分更新。验证码、权限拒绝、网络故障、未知响应与会话失效各有提示；校园会话失效不会退出本地账号。状态读取返回已保存的快照，不表示上游实时状态。

同步失败时，提示区分别标明学期列表、课表或成绩。展开“同步诊断（不含账号或 Cookie）”可查看请求阶段、GET/POST、固定服务域名/路径、传输错误类别及耗时；不包含查询字符串、表单、账号、密码、验证码、cookie、代理地址或上游响应正文。证书校验、TLS 连接、DNS、超时、连接中断/拒绝和不完整 HTTP 响应分别分类；“没有访问权限”不误报会话过期。教务 JSON 查询携带 AJAX 请求头，CAS 表单保持独立。

真实联调由本人在本机界面输入凭据。协作排障可提供页面报错和上述诊断；无需发送完整账号、数据库、浏览器 Cookie 或 HAR。修改代码后需要重启本地服务并刷新页面；重启会清除内存中的教务会话，需要重新登录，但已保存快照仍保留。

密码只存在当次请求与加密过程，不写入数据库、配置、审计或模型输入。CAS 表单令牌与验证码会话仅在进程内，登录准备有效期五分钟；CAS 主会话与教务 cookie 均只在进程中使用，主会话仅发送给认证域名，可即时申请一次性业务票据；访问校验有效期最多一小时。过期在下一次访问时清除。退出本地账号、断开连接或关闭服务时也清除连接。退出本地账号保留已同步快照；新通行证入口按已验证的登录标识选择资料账号，重登保留对应缓存；账号切换不合并快照。旧接口在手动更换校园身份时仍清除旧快照，避免混用。

SQLite `campus_snapshots` 按本地账号隔离，数据库当前未加密。校园快照不加入文档检索或发送给 OpenAI。审计只记录操作和状态码。解析、模型输出与上传文档均无法调用校园连接器。

## 实现与协议依据

2026-10-12：`campus.py` 保留兼容导入、会话生命周期与原批次编排；CAS 实现在 `campus_auth.py`，网络策略在 `campus_network.py`，平台解析在 `connectors/`，缓存通过 `campus_repository.py`。`campus_profiles.py` 仅为兼容导入。统一服务、字段契约、范围缓存、通知摘要和验证边界见 [连接器指南](connectors.md)。`campus_routes.py` 继续负责本地认证和 HTTP 参数转换；`static/campus.js` 保持现有展示。新表以 `CREATE TABLE IF NOT EXISTS` 加入已有数据库。Cookie 发送按站点隔离，CAS 主 Cookie 只发认证域；保留 HTTPS、固定可信站点及逐跳校验，不接受用户或模型传入 URL。

认证顺序：获取 execution → 同会话获取公钥 → 加密并提交一次密码 → 确认有效 CAS cookie → 保留内存主会话并即时换取教务 service ticket → 验证回调域名、路径及票据 → 建立站点会话 → 用教务只读菜单接口验证权限。单独的 302、cookie 或 JS 补丁页不作为登录成功依据。
