# 第一优先：试点准备与验收

版本：0.3.0-pilot.1。分支：feature/pilot-readiness。基于 bc42ed1 的连接器、认证恢复和网络策略；不修改 main。

## 获取和启动

下载本分支的 ZIP 后完整解压，安装 Python 3.12，Windows 双击 start.cmd；macOS/Linux 执行 sh start.sh（尚未实机验证）。首次安装需联网，后续使用相同入口。启动窗口保持打开，Ctrl+C 停止。左侧版本应显示 0.3.0-pilot.1。

如果 8765 已被其他版本占用，先在其终端停止，或使用 `python launch.py --port 8766`。不要仅刷新旧网页来升级。项目默认各用自己的 data 目录。

升级旧资料：停止旧版和新版，备份旧版整个 data 目录，再复制到新版；不要在两份服务运行时共用或复制活动数据库。启动器不自动搬运账号、会话或校园资料。

## 本人真实验证（待完成）

1. 在本机页面亲自输入通行证或验证码，凭据不发给协作者；仅提交一次，失败按界面诊断处理。
2. 与官方网页核对当前学期的课程、时间、地点，以及若干成绩；记录一致/不一致和信息获取时间，不记录个人明细。
3. 退出并关闭服务，重新启动；检查本人缓存和“离线/过期”标记，不把缓存误认为刚同步成功。
4. 检查认证失败或网络中断后，表单可恢复、已有资料保留。不要故意反复输错密码来测试锁号；密码失败、验证码和过期场景优先用合成测试。
5. 当前网络策略默认 direct；确需系统代理时，在启动进程前设置 CAMPUS_NETWORK_POLICY=system。直连失败不自动重复提交密码或切换网络。

记录格式：版本、操作、成功/失败、错误码、耗时、是否保留缓存。不要记录密码、Cookie、票据、姓名、学号或完整成绩截图。
