# 淡蓝色对话工作台

分支：feature/blue-chat-ui。版本：0.3.0-ui.1。

主区域改为对话工作台，移除大幅宣传区与概览卡片；左侧包含重要信息、资料/学业导航、设置与插件/Skills 入口。重要信息来自当前账号待办和已有教务通知缓存，不产生新的远端同步；通知尚无缓存时明确留空。插件与 Skills 页面为入口预留，不宣称支持安装或执行。

支持 Enter 发送、Shift+Enter 换行，输入法组词时不发送。新对话清空当前页面聊天，回答进行中拒绝重置。登录后默认打开对话页，校园同步机制继续保留。

验证：194 项 Python 回归测试通过；浏览器使用隔离合成账号验证注册、导入演示、公告板待办、Enter 发送、引用回答、插件入口与设置导航。1366px 桌面和 390px 窄屏检查无文档横向溢出，检查时控制台无 error/warn。未使用真实账号或模型密钥。
