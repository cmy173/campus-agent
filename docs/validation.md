## 2026-10-09 变更：登录改为校园通行证（统一身份认证）

应团队要求，登录由「本地账号 + scrypt 密码哈希」改为「校园通行证」：学号 + 统一身份认证密码，后端直连 `zjuam.zju.edu.cn` 的 CAS 换取一次性票据（借鉴 Celechron 与本地参考实现 zjuhelper 的 RSA/CAS 流程）。`users` 表移除 `password` 列，账号即学号；密码不写库/不写盘/不写日志，认证失败只尝试一次以防风控锁号。

自动化：`python -m unittest discover -s tests -v` 共 38 项。本次新增/改动均通过：

- `test_passport.py`（10 项）：RSA 无填充加密与十六进制指数、UTF-16 高代理项对齐、CAS 成功换票返回学号身份、被拒时**不重试**（恰好 3 次请求）、302 无 ticket 判失败、缺 execution 判失败、网络错误提示、空凭据不触网。
- `test_web.py`：登录/退出、错误通行证 401、正确通行证 200 且身份为学号、`users` 表无 `password` 列且无密码明文残留、register 端点已移除（404）、非法学号在触达 CAS 前被拒（400）、owner 隔离（bob 看不到 alice 的资料操作审计）。

浏览器：本机启动服务，登录框正确渲染为「校园通行证登录 / 学号 / 统一身份认证密码 / 登录工作台」，注册-登录切换已移除；除未登录时 `/api/me` 预期返回 401 外无 JS 控制台错误。

数据库迁移：对含旧 `password` 列的库用新版 `Store` 打开，`password` 列被删除、既有账号保留（已用脚本验证）。
