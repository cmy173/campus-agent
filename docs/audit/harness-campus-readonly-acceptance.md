状态：已确定下一轮标准，尚未验收。对应任务书：`docs/agent-design/harness-campus-readonly-task.md`。上一轮导出与复习验收结论不替代本合同。

实施方：开发 DeepSeek Harness；验收方：原 Codex 对话。根据任务完成证据验收，不要求新增类、平台或抽象层。

## 现有证据和验证边界

基线 `650a9348e859ee24544c85fce1a3f397ae3e2345`。本轮开始前 Codex 隔离探针确认：工作区 query(refresh=False) 遇到缓存 AUTH_REQUIRED 可以进入自动重登再 sync；外部边界均为合成替换，学校网络请求为零。这属于调用行为证据，不是真实认证结果。与默认缓存查询契约冲突，修复还须保留显式同步的授权恢复路径。

产品是单人本机部署，不凭 owner=local 声称支持多人托管。隔离验收覆盖课程/连接/对话授权、不同本机工作区、适配器会话及旧账号导入边界。

## 十六类可复跑案例

| ID | 行为 | 目标断言 |
| --- | --- | --- |
| C01 | 缓存缺失、过期、AUTH_REQUIRED、重启后 query/status/学业缓存读取 | 实际 transport/认证/浏览器私有接口计数为零；旧缓存、时间、新鲜度和结构化错误准确 |
| C02 | 显式 sync，自动重登开启/关闭、验证码、拒绝、限流 | 允许时最多一次认证恢复；关闭时不提交密码；不切通道重投；冷却及原 scope 保留 |
| C03 | 未知平台/能力、非法类型、URL/owner/Cookie 额外参数 | 标准错误且危险 IO 为零，不降级任意请求 |
| C04 | 两个对话窄 scope、两个连接、两个隔离工作区 | 不串课程/任务/缓存/会话，不因知道 ID 就有读取或取消权限；不暗示多租户支持 |
| C05 | 教务或一个课程平台失败，另一个仍正常 | 分平台错误与缓存隔离，已有结果可用，不整体断开或清空 |
| C06 | 超时、DNS/连接失败、429、401/过期、403、验证码/MFA、协议变化 | 调用方用错误码区分；有限安全重试，不解析文案驱动控制流；首次失败被保留 |
| C07 | 页二失败/中断后恢复，重复同步，同一页重放 | 不跳页、不重复，不误标完整，不清未返回记录；opaque cursor 绑定范围 |
| C08 | 成功空响应、部分空响应、学期范围缩小、显式删除信号 | 分别处理，不把部分/缩小范围当全量删除，未知仍未知 |
| C09 | 并发 sync/刷新、断开、清数据与恢复竞争 | 同账号并发有界；撤销不复活授权；断开保留资料，清数据严格限定范围 |
| C10 | system/direct、恶意跳转、跨域 Cookie、带 ticket/签名 URL 错误 | 仅校园 transport 策略变化；TLS/可信域/重定向护栏保留，模型/日志/普通缓存无凭据 |
| C11 | 通知发现→正文→回答 | 来源实际被读取，日期/标题/范围可核对，摘要与正文/附件状态分开，不夸大全校覆盖 |
| C12 | 平台发现→分页挂接→sync job→资料/作业读取→回答 | 真实 API、worker、服务和存储参与；只受理不算完成；答案依据来自实际材料，截止未知不猜 |
| C13 | 课表/校历→学习任务→计划预览 | 时间来源与精度保留，按实际约束避让，缺任务/日期如实受阻，预览不写正式安排 |
| C14 | 认证失效→持久化等待→成功认证通知→恢复，另测重启/撤销 | 恢复原只读目标且不扩 scope、不重复副作用；未授权步骤明确停住；无空转轮询 |
| C15 | 模型可见工具、tool ID、多调用、结果回传、消费与完整回答 | 实际 Harness 轨迹可核对；不由脚本代替模型选择；控制策略不会排除必要工具 |
| C16 | 公开搜索、网页获取、校园 HTTP、浏览器四种能力状态 | 分别报告可达/认证/正文/最终结果，浏览器通不等于后端通，HTTP 能请求不等于具备搜索 |

C01—C16 可由多项测试覆盖。可恢复错误和诚实受阻可符合断言；外部缺条件必须标注 blocked，不能计为已完成业务。保留修改前失败，修改后复跑相同输入；涉及语义迁移的旧测试解释清楚并保留安全约束。

## 四级证据与评测

1. 直接业务/工具：没有模型，定位实现和权限。
2. 实际 API + 安装的 Harness + 真实业务服务/worker + 合成学校响应/受控模型：覆盖三条完整链及恢复。不允许 mock 成品业务结果来“通过”链路。
3. 真实配置模型 + 固定合成学校数据：四项各一个独立会话，检查自主选工具、消费结果、目标完成。单回合 12 模型/40 工具/150 秒，恢复场景最多两个回合，用户等待单列。真实搜索与合成学校部分仍须分别标记。
4. 真实公开网络及已授权校园：公开请求无凭据，校园请求仅合法最小只读；没有账号/预算/网络就明确待验证。历史校园观测不能变成本轮新验证。

记录每次的工具可见性、选取、实际执行、错误层、业务结果、人工介入、耗时、模型/工具调用数、usage。没有账单金额记 unknown。

分母固定：受控链以合同任务计，工具成功率用实际调用计，业务完成率以最终目标计，安全拒绝/预期错误单列。真实模型四项仅是小样本诊断，不能宣称统计成功率提升。失败后重试是新增记录，不能替换首次失败。

## 独立验收步骤与结论

Codex 收到成果后：

1. 重读 git diff、依赖/权限变化、源码哈希和结果索引，确认前后测同条件且未覆盖他人工作。
2. 自行复跑 C01—C16，至少增加一个实施方未用的边界输入；独立运行三条真实业务链和认证恢复。
3. 检查模型实际可见工具、call ID、结果回传、最终答案及来源；不能仅看 Harness succeeded。
4. 复跑受影响回归和完整 API/连接器/契约；runtime/UI 改动对应其完整回归，保留前轮文档交付与复习能力。
5. 对真实证据独立抽验；没有有效账号/预算时，明确将对应部分留为未验收，不用受控成绩代替。
6. 给出“工程部分通过 / 需修改 / 外部验证待完成”，分别列出可用平台、已验证范围和阻塞条件。只有全部实际要求有证据才可整体通过。

凭据泄露、越权、未授权校方提交、缓存误删、虚假完成直接阻止通过，不用平均分抵消。不要求增加空壳连接器或重写 Harness，也不因没有扩大架构扣分。
