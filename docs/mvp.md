# MVP 范围与实际状态

更新：2026-10-08 / v0.2。阶段 0 为设计和 CLI；本轮完成本机 Web 闭环。真实用户试点、模型实测和生产验收尚未完成。

| 需求 | 已实现 | 限制 |
|---|---|---|
| R01 Web | 5 个页面、解析状态、移动布局 | 无模型流式输出 |
| R02 上传 | UTF-8 TXT、文本 PDF、DOCX、PPTX；20 MB | PDF/PPTX 最多 200 页；无 OCR、旧 DOC/PPT |
| R03 问答 | 本地关键词匹配、定位引用、可选 OpenAI | 不是向量检索；真实模型未联调 |
| R04 通知 | 候选待办、年月日时分提取、人工核对 | 相对日期和多日期不推断；未测真实语料准确率 |
| R05 推荐 | Mock 活动与冲突规则展示 | 未实现真实活动导入或学分认定 |
| R06 Connector | Mock 能力声明、固定只读业务路径 | 无多步骤 LLM Agent 或真实平台工具 |
| R07 数据 | 校园通行证登录、owner 校验、级联删除、审计 | 不是生产安全认证；未在真实 CAS 联调 |
| R08–R12 | 保留规划 | 课程规划、定时同步、音视频、报告分析和平台执行待开发 |

## 可演示闭环

校园通行证登录 → 导入通知/课程资料 → 等待解析 → 提问 → 点击引用 → 核对待办时间 → 标记完成 → 删除资料。模型默认不启用。

## 正式试点前的验收

1. TXT/PDF/PPTX/DOCX 各 5 份授权样本，核查正文与来源定位；扫描件明确失败。
2. 标注 30 条通知，覆盖相对日期、多截止、重复与过期，报告误提取、漏提取和错日期。
3. 30 个可回答问题与 10 个无依据问题，人工核对模型回答和引用。
4. 核实试点院系/年级活动规则后，再验收真实活动推荐。
5. 在实际部署环境测试隔离、资源限制、备份恢复和删除。

原设计的明确日期准确率 ≥95% 仍是目标，未用真实标注集证明达到。合成测试结果见 validation.md。
