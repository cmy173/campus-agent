## 目前难点

- go.zju.edu.cn 在当前 Web 工具及浏览器中均连接失败，不能声称已核实全部导航目录。
- 网站地址和公开办事说明不构成 API 接入权限。
- 没有用户配置的模型，无法验证账户可用性、额度和真实问答效果。
- 相对日期、复杂表格、课表周次、OCR 与音视频需要专门语料和处理方案。
- 引用 ID 有效只证明来源存在，不证明模型每句话正确。

这些依赖不影响当前本机版本运行。下一步建议先用少量授权资料做实际评测。
