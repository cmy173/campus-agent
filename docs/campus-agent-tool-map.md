# Campus Agent 全工具地图

由 `python tools/campus_bench/build_tool_map.py` 从真实注册表导出。领域工具 34 个；Benchmark 场景 44 个。真实 API 日志扫描 232 次运行，其中 71 个批次已捕获调用级 schema。

## 运行时边界

领域工具由 `tools.py:SPECS` 注册，名字映射到 Harness 的 `campus_*` schema。Native/provider/MCP 工具由 SDK 和运行时配置注入，静态源码不能枚举所有用户 MCP 工具；清单将其单独列出，并区分代码注册、模型 schema 注册与真实轨迹观察。内部 provider 请求会在模型事件中记录脱敏、限长的可见 schema 快照；超限时保留摘要哈希，不将模型本轮可见范围外推为全局能力。

历史 schema 对照把真实 Agent 轨迹中的模型调用快照与当前工作树工具注册表逐字段比对：24264 个工具级观测中，5375 个有描述或参数差异。这是跨历史版本的差异统计，不是当前运行故障结论；工具级记录包含对应批次是否有 Agent runtime 源指纹，但该指纹不覆盖独立 API 进程中的 schema 注册表，因此当前服务匹配仍标记为未验证。字段级差异见 JSON `runtime_schema_drift_observations`。

主路径：用户输入 → Agent API turn → Harness/DeepSeek SDK → provider/native `tool/call` → `campus-plugin.mjs` → `/api/v1/agent/internal/tool` → `tools.execute` → router/action/store 或 CampusWorkspace → 结构化工具结果 → 下一模型步。Native 搜索/网页读取绕过 API 域工具路由，凭 Harness 事件追踪。

## 运行追踪覆盖限制

- 域工具 journal 可记录工具名、调用参数、返回 envelope、错误状态和 duration；单任务预算/超时/完成状态由 benchmark runner 记录。
- Native provider 成功/错误事件记录模型本轮可见名称、选择结果，以及经敏感字段脱敏、最多 64,000 字符的 schema 快照和 SHA-256；超出上限时仅记录摘要、数量和哈希。
- Harness `tool/call`、`tool/result` 事件提供 native 工具执行轨迹；独立 native 工具精确耗时和每个外部人工步骤仍不可稳定观测。
- 官方 provider 的 Token 用量由 assistant/message usage 事件提供；模型请求墙钟耗时来自 `llm/stream` 包络，包含 SDK stream 处理。
- API 域错误会保留结构化错误码；浏览器/MCP 工具服务端错误受运行时配置影响，需通过当次 trace 归因。
- 真实校园证据：本批只读 `campus.sync` 已返回 18 门课程、fresh/complete（无课程内容存入 benchmark）；真实 Agent traces 已调用 `campus.status`、`connections.status`、`web_search`、`web_fetch`。这些不证明其余工具可在真实校园环境工作。

## 已知覆盖缺口

现有 44 场景中 ERR-04/05/07/08 因缺少故障注入、VPN 授权目标/切换夹具、DOM 变化 fixture、人工认证暂停恢复而 blocked；剩余场景虽标 runnable，并非都已有确定性 oracle 或做过真实测试。作业工具已有直接单测覆盖日期排序、稳定游标续页和参数边界；ERR-11 隔离 Harness E2E n=3 验证空缓存的 stale/partial 语义与结果回传。BUS-12 隔离 Harness E2E n=3 验证游标结果回传、续页和唯一性；真实模型选择/表达仍未验证，其他工具家族的缓存、参数、结果回传和写入授权覆盖仍不完整。
