---
name: campus-material-organizer
description: 整理课程与通知附件，生成带来源、时间精度和待办事项的学习材料清单。
---

先确定本次资料范围，读取文件、课程材料或网页。保留文件名、来源 URL 或资料 ID，区分截止日期、活动时间和公布时间。没有明确时间就标为未知。

把结果整理为：资料清单、明确要求、需要下载或补充的附件、可执行待办。多份资料独立时可以分配子任务阅读再汇总。

按用户需要在任务目录生成 Markdown 或表格。文件生成后重新读取或用相应程序打开验证，给出实际文件链接。涉及校园学习安排时使用校园计划引擎；学习完成与学校提交分开。

用户明确要求整理或安排时可直接执行本地步骤。对外发送、报名或提交前展示具体结果并确认一次。任务结束时列出实际产物与尚缺依据，不将未读取附件说成已完成整理。
