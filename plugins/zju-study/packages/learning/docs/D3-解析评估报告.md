# D3 解析评估报告（小样本）

- 日期：2026-10-09 ｜ 智能体 D ｜ 阶段：M1
- 范围：`packages/learning/samples/evaluation/` 5 份**自编**评估文档（非真实课件）
- 结论口径：**仅报告本批样例上实际观察到的结果，不泛化为“所有课程/真实课件准确率”**。

## 1. 方法

1. `tests/make_eval_docs.py` 确定性生成 5 份文档（固定 zip 时间戳；重复生成字节一致）；
2. 对照源码文档**人工标注**正文、页码/幻灯片位置与文本偏移，写入 `samples/evaluation/labels.json`；
3. `tests/test_eval_samples.py` 用 `parse_document`（含 `ParseContext` 溯源）实测输出对照标注：
   状态、单位数（页/幻灯片/段落）、片段数、全文拼接逐字一致、定位与标题层级、限制说明、确定性复跑。

复现命令（`packages/learning/` 下）：

```bash
.venv/Scripts/python tests/make_eval_docs.py        # 重建样例（字节稳定）
.venv/Scripts/python -m pytest tests/test_eval_samples.py -q   # 对照标注
```

## 3. 逐份观察

- **doc01（中文讲义）**：6 个片段按文档顺序；`heading_path` 正确嵌套（`第2章 线性表` → `2.1/2.2 顺序/链式存储`）；正文与源文逐字一致；文本偏移 0→214 在片段间以“+1（`\n` 分隔符）”连续衔接，可回看原文。
- **doc02（中文课件）**：4 张幻灯片的 `locator.slide` 1–4 如实保留；第 4 张为**纯图片页**——不产生任何文本片段，但幻灯片总数（units=4）仍正确；表格提取为 `比较项 | 顺序表 | 链表…`（行以 `\n`、单元格以 ` | ` 连接）；演讲者备注正确归到第 3 张（`kind=notes`）；限制说明列出“2 处图片、1 个表格”。
- **doc03（文本层 PDF）**：3 页各出“标题 + 正文”2 个片段；标题层级 `1 Introduction`(L1)、`1.1 Arrays`/`1.2 Linked lists`(L2) 识别正确；全文拼接与源文逐字一致；限制说明保留“按文本层提取，图像/公式图形不还原”。
- **doc04（扫描型 PDF）**：`status=needs_ocr`、0 片段、页码数 2 如实返回；`message` 明示“疑似扫描件/图片型文档，需要 OCR；未按失败处理”——满足“扫描件返回需 OCR 状态而非失败”的验收口径。
- **doc05（含表格/公式/插图的 DOCX）**：表格 1 个（4 行）正常提取；**公式（OMML）与插图未提取为文本**，且不出现在任何片段（负例断言 `x^2` 不出现）；限制说明逐项列出图片/公式/表格；文本偏移连续。

## 4. 观察到的限制（如实列示，不作泛化）

1. 本批全部为**自编**样例；其中 PDF 夹具正文为 ASCII（手工构造 PDF 不嵌入中文字体），**中文 PDF 未经本批样例验证**——中文正文路径由 DOCX/PPTX 样例覆盖。真实课程材料（含中文 PDF/扫描件的比例）待 A/B 提供真实样例后另行评估。
2. 标题识别为启发式（DOCX 样式/`outlineLvl`、编号样式正则）：本批样例均命中；启发式未命中时仅影响层级展示，正文与定位不丢（已在 D2 测试矩阵覆盖该口径）。
3. 无文本页（纯图片页/扫描页）不产生文本片段，但页/幻灯片计数与状态如实反映（doc02 第 4 张、doc04）。
4. 生成夹具的一个观察：pypdf 对**完全空行**在提取时可能丢失（导致段落不拆分）；本批夹具改用“仅空格行”保留分块信号。对真实 PDF 的段落切分质量依赖提取文本的换行/空行形态，属已知限制。
5. **时间戳核对不在本批文档集内**：回放字幕的起止秒数核对由 D4 覆盖（`samples/transcript/` + `tests/test_transcript.py`）。

## 5. 结论

- 在本批 5 份自编样例上，解析输出的**正文、页码/幻灯片位置、标题层级、文本偏移**与人工标注**全部一致**；扫描型样例按“需 OCR”正确归类；表格可提取、公式/插图按限制说明不伪装。
- 该结果**只适用于本批样例**，不构成对真实课程材料准确率的推断。
- 评估脚本可重复运行；后续获得真实脱敏样例后，可用同一标注/对照流程扩展本报告（见 `samples/evaluation/labels.json` 结构）。
