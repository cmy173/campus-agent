## 2. 输入输出契约

### 2.1 公共 API（`from learning import ...`）

| 函数 | 签名 | 说明 |
|---|---|---|
| `build_tasks` | `(resources, assignments, recordings, options: TaskGenOptions \| None) -> TaskGenResult` | D3 规则生成；确定性；`options` 含 `existing_tasks` / `hints` / `user_tasks` / `config` |
| `generate_plan` | `(tasks: list[LearningTask], availability: Availability, options: ScheduleOptions) -> Plan` | D4 排程；纯函数 |

### 2.2 对象 JSON 形状（`to_dict` 输出，建议 B 据此补 `contracts/schemas/`）

```jsonc
// LearningTask（核心字段）
{ "id": "t:crs_cs261:reading:第4章-树与二叉树(课件)",
  "course_id": "crs_cs261", "type": "reading", "title": "第4章 树与二叉树（课件）",
  "estimated_minutes": 138, "due_at": null, "due_precision": "unknown",
  "prerequisite_ids": [], "source_refs": [ /* source-ref.schema.json 同形 */ ],
  "status": "pending",              // pending | completed | cancelled
  "completion_criteria": null, "estimate_provenance": "inferred",
  "estimate_confidence": null, "splittable": null, "priority": null }

// PlanBlock
{ "id": "blk:...:0", "task_id": "t:...", "starts_at": "2026-10-14T19:00+08:00",
  "ends_at": "2026-10-14T19:46+08:00", "locked": false }

// UnassignedItem
{ "task_id": "t:...", "reason_code": "DEADLINE_PASSED", "message": "…（含中文解释）",
  "needed_minutes": 90, "available_minutes": 0, "max_contiguous_minutes": null,
  "deadline": "2026-10-08T23:59+08:00", "suggestion": "…" }

// Plan（generate_plan 输出；id/version 为 null，由 B 落库时分配）
{ "id": null, "version": null, "input_revision": 1,
  "horizon_start": "…", "horizon_end": "…", "blocks": [], "unassigned": [], "warnings": [],
  "summary": { "capacity_minutes": 1020, "scheduled_minutes": 727, "locked_minutes": 60,
               "scheduled_task_count": 10, "unassigned_task_count": 1 } }
```

- 时间字符串全部 ISO 8601 带偏移量（本包统一 `+08:00` 渲染；若 B 需要 UTC 输出，告知后可加配置）。
- `WarningItem`：`{code, message, task_ids[], details}`；排程告警码见 §2.4。
- **稳定匹配键**：`t:{course_id}:{type}:{external_id 或 slug(标题)}`；slug 为 NFKC 规范化后空白/斜杠/冒号转 `-`；
  >120 字符截断加 sha1 摘要。相同输入重复生成得到相同 ID；`hints`/`user_tasks` 按此 ID 或 `{course_id,type,title/external_id}` 匹配。

### 2.3 未安排原因码（`UnassignedItem.reason_code`，对齐《04》D5 口径）

`DEADLINE_PASSED` / `INSUFFICIENT_WINDOW_BEFORE_DUE` / `INSUFFICIENT_TOTAL_TIME` /
`TASK_TOO_LONG_INDIVISIBLE` / `FRAGMENTED_WINDOW` / `DEPENDENCY_CONFLICT` / `INVALID_TASK`。
启发式失败（后四类的部分情形）消息均带“当前策略未能安排”，**不宣称数学不可行**。

### 2.4 排程告警码（`Plan.warnings[].code`）

`EMPTY_HORIZON` / `DUPLICATE_TASK_ID` / `INVALID_DURATION` / `INVALID_DUE_DATE` /
`UNKNOWN_PREREQUISITE` / `DEPENDENCY_CYCLE` / `LOCKED_TASK_NOT_FOUND` /
`LOCKED_BLOCK_INVALID` / `LOCKED_BLOCK_OUTSIDE_HORIZON` / `LOCKED_BLOCK_OUTSIDE_WINDOW` /
`LOCKED_BLOCK_EXCEEDS_DAILY_LIMIT`。
任务生成告警（`TaskGenResult.warnings[].code`）：`DUPLICATE_CONTENT`（内容哈希重复合并）/
`TASK_VERSION_UPDATED`（同名新版本合并）/ `UNSUPPORTED_EXTENT`（无法按页数估算，回退默认时长）/
`MISSING_DURATION`（回放缺时长按默认估算）/ `DUPLICATE_TASK_ID`（生成结果 ID 冲突）/
`EXISTING_TASK_UNMATCHED`（已有任务无对应来源，原样保留）/ `HINT_UNRESOLVED`（提示无法匹配）。

### 2.5 校验器违规码（`validate_plan`，联调自查用）

`BLOCK_INVALID_TIME` / `BLOCK_OVERLAP` / `BLOCK_OUTSIDE_WINDOW` / `BLOCK_AFTER_DEADLINE` /
`UNKNOWN_TASK_BLOCK` / `NON_PENDING_TASK_SCHEDULED` / `DAILY_LIMIT_EXCEEDED` /
`PREREQUISITE_UNAVAILABLE` / `PREREQUISITE_UNSCHEDULED` / `PREREQUISITE_ORDER_VIOLATED` /
`DURATION_MISMATCH` / `LOCKED_BLOCK_NOT_PRESERVED`。
锁定块与既有事实冲突时如实报告（如 `locked_conflict` 样例允许 `DAILY_LIMIT_EXCEEDED`，计划不假装完全有效）。

## 5. 已知限制

1. 排程为**确定性启发式**（按截止+优先级靠前填充），不承诺全局最优；“未能安排”不等于“无解”（消息已明示）。
2. `max_chunk_minutes=60` 会将 >60 分钟任务预拆为均匀小块（120→2×60，138→3×46，150→3×50）；
   如需整块排入，B 调大该参数即可，无需改代码。
3. 单块可跨午夜（跨日部分按日分别计入每日上限）；不禁止午夜块。
4. 时区仅按用户单一时区展开（默认 `Asia/Shanghai`）；不处理夏令时切换（当前目标时区无夏令时）。
5. `build_tasks` 的时长估算为页面/幻灯片/播放时长的确定性规则；**模型推断（D6）未接入**，
   `estimate_provenance` 目前只会是 `platform`（规则可算）或 `inferred`（兜底默认值）。
6. D1（文档解析）、D2（回放文本整理）、D5（局部重排与解释）未实现——第二批进行；
   局部重排将复用 `generate_plan` + `locked_blocks`（已可表达“固定其余块、重排部分”的基础场景）。
7. 大盘性能未验证（样例 ≤ 11 任务、64 天窗口内）。
