- 交付物：薄封装 `build_tasks_json`（`src/learning/taskgen.py`）+ 集成测试 `tests/test_b13_integration.py`（6 项）

## 1. 调用入口（唯一新增入口，纯函数）

```python
from learning.taskgen import build_tasks_json          # 或 from learning import build_tasks_json

result = build_tasks_json(payload)                     # -> {"tasks": [...], "warnings": [...]}
```

- **契约形状 JSON 进、JSON 出**：B 落库行的 `to_contract()` 输出可直接传入，**无需手工字段转换**；多余键忽略。
- 无数据库、无网络、无平台依赖（`test_package_import_pulls_no_db_or_http_dependencies`）；相同输入输出逐字节一致（确定性）。
- `tasks` 按 `id`（稳定匹配键）升序；`tasks[].id` 即 **match_key**。

## 2. 输入 payload

| 键 | 必填 | 形状与语义 |
|---|---|---|
| `resources` | ✓ | resource 行（`to_contract()` 输出，含 `extent_value/extent_unit`、`content_hash`、`source_refs`）。**D 不做 parse_status 过滤**：传哪些生成哪些（建议 B 明确口径并在 job 内记录；扫描件/解析失败件是否建阅读任务由产品决定） |
| `assignments` | ✓ | assignment 行（`due_at` 为契约 ISO 时间；B 的 `iso_utc()` 输出 `Z` 结尾原样透传） |
| `recordings` | ✓ | recording 行（`duration_seconds` 换算观看时长；`transcript_status` 六态消费见 A10 对齐说明） |
| `existing_tasks` | ✓ | 该课程**全部任务行**（原样传入即可），封装自动分流：**未归档 + 有稳定键**（`match_key` 字段，或直接回传的 `t:` 前缀 `id`）→ 与再生成结果按稳定键对齐并保留人工修正；**未归档 + 无稳定键**（`tsk_` 主键的人工任务）→ 原样保留、不产生告警；**已归档**（`archived_at` 非 null）→ 忽略（软删除不复活） |
| `user_tasks` | — | 用户自建任务（D 形状）；一般无需单独传（`existing_tasks` 已覆盖） |
| `hints` | — | 用户提示（补前置/改耗时），形状同 `TaskHint` |
| `config` | — | `TaskGenConfig`（`minutes_per_unit` / 兜底时长 / D6 校正系数 `type_estimate_factors`）；缺省用默认值 |

说明：**本版规则生成不消费 ContentChunk**（chunk 用于检索与后续模型增强）；B13 无需传 chunks。若未来要按内容估算，走变更流程。

## 4. match_key 与幂等（B13 落库建议）

1. 冻结契约 `learning-task.schema.json` 已有 `match_key` 字段（可空）——生成任务落库：**主键另配不透明 `tsk_`，`match_key` 存 `tasks[].id`**；用户手工任务 `match_key=null`。
2. **upsert 伪代码**（推荐）：

```python
for task in result["tasks"]:
    row = lookup_by_match_key(db, task["id"]) if not is_tsk_id(task["id"]) \
          else db.get(LearningTask, task["id"])          # 人工任务按主键命中（幂等 no-op）
    if row is None:
        insert(copy_contract_fields(task), id=new_id(...), match_key=task["id"])
    elif row.archived_at is not None:
        continue                                          # 已归档：跳过，不复活、不新建
    else:
        update_derived_fields(row, task)                  # title/due/source_refs 等平台派生字段
        row.revision += 1                                 # 既有并发控制语义由 B 维护
```

3. **幂等成立条件**：重复触发（重新解析后自动派发或手动触发，两条路径同一函数）时把既有行传回 `existing_tasks`，D 按稳定键对齐 → 相同 `match_key` 集合、逐字段一致（测试：`test_repeated_generation_is_idempotent_with_existing_rows`）；B 侧以 `match_key` 为唯一键 upsert，不产生重复任务。
4. 稳定键构成（D0 §2.2）：`t:{course_id}:{type}:{external_id 或 slug(标题)}`，>120 字符截断加摘要；`source_refs` 有 `external_id` 时标题变更不变键。**请确保传入 `source_refs`**（B 行 `refs_for(...)` 已含）。

## 5. 人工修正保留（与 B 存储语义对齐）

- **保留（不因再生成覆盖）**：`status`（completed/in_progress/cancelled 原样保留）、`estimated_minutes` + `estimate_provenance`、`completion_criteria`、`splittable`、`priority`、`prerequisite_ids`。→ B 的 PATCH/反馈改动经 `existing_tasks` 传回后自动生效（测试：`test_user_corrections_survive_regeneration`）。
- **随来源更新（不受保留语义冻结）**：`due_at`/`due_precision`（作业截止变化跟随）、`source_refs`、`title`（键随 `external_id` 稳定时）。
- 来源被移除的既有任务：原样保留 + `EXISTING_TASK_UNMATCHED` 告警（供 C11 提示）。
- 冻结契约任务表无 `completion_criteria`/`estimate_provenance`/`splittable`/`priority` 字段（`additionalProperties: false`）：建议 B13 将**完整生成结果**（tasks 全字段 + warnings）随 job 结果返回供 C11 展示；如需持久化这些字段，走 B6 兼容变更流程。

## 6. warnings（C11 直接展示）

七类生成告警码（稳定）：`DUPLICATE_CONTENT`（内容哈希重复已合并）/ `TASK_VERSION_UPDATED`（同名多版本）/ `UNSUPPORTED_EXTENT`（无法按篇幅估算回退默认）/ `MISSING_DURATION`（回放缺时长）/ `DUPLICATE_TASK_ID`（生成 ID 与用户任务冲突）/ `EXISTING_TASK_UNMATCHED`（既有任务无对应来源）/ `HINT_UNRESOLVED`（提示未匹配）。
`message` 为面向用户的中文文案（C 可直接渲染）；`task_ids` 供点击跳转；`details` 为诊断信息。测试：`test_all_warning_codes_have_display_ready_messages`（七码齐备 + 文案非空 + JSON 可序列化）。
