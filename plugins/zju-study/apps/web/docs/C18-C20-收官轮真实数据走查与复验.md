- 走查方法（同 C14/C15）：在页面内创建**同源离屏 iframe**（`position:fixed; left:-99999px; width:<档位>px; height:900px`）逐路由加载；收束 = 无 `.ant-skeleton/.ant-spin-spinning` 且 body 文本 > 40 字；交互用 `element.click()` 与 iframe 内合成 `KeyboardEvent`；等待用 MessageChannel/setTimeout（容忍后台节流）。
- **隐藏标签页轮询限制与破解（本轮方法要点）**：react-query 的 `refetchInterval` tick 被 focusManager 焦点态门控，隐藏页不发 `visibilitychange` 导致卡在首次 GET。本轮通过覆写 `document.visibilityState/'hidden'` 并在 **window** 派发 `visibilitychange`（`bubbles:true`）与 `focus` 事件恢复轮询——这是上一轮观测不到「排队中→成功」转换的根因（此前合成事件在 document 上派发且 `bubbles:false`，未到达 window 层监听）。
- 口径：本文件一切「已验证」均以**真实浏览器 + 真实后端数据**为准；jsdom 组件测试单独标注为「模拟验证」。
