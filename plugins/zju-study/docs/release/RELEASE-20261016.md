# 0.3.0-alpha.1 发布说明

发布整理日期：2026-10-16。Python 适配器版本按 PEP 440 写作 0.3.0a1；后端保持 0.2.0-local。

## 本次交付

- 通用 Agent 插件：根目录 plugin.json，附自定义 manifest schema；不绑定某个 Harness 的私有格式。
- 基于 MCP 官方 Python SDK 1.30.0 的 stdio 服务：40 个具名工具、实际 SDK 生成的 JSON Schema、宿主 MCP 配置示例、调用流程及参数示例。
- 保留已有 REST API、网页配置界面和相邻源码式 Windows EXE 启动器。
- 工具只访问指定回环 API，不导出学校登录 Cookie 或模型密钥；没有任意 URL 代理。文件导入仅使用宿主明确提供的绝对路径，后端按现有文件限制校验。
- 同步、解析、出卷、课堂总结均复用现有后台队列，返回 job 后轮询；不会把受理当作生成成功。

## 验证

MCP 初始化握手、tools/list 和 tools/call 已用真实 stdio 子进程与隔离 HTTP 测试后端验证；验证了默认参数、分页参数、无效参数拒绝及无副作用状态查询。实际本机后端 --check 通过。

插件、连接器与教材相关测试共 335 项通过，另 7 个子测试通过。页面改动沿用上一轮已通过的生产构建与任务展示测试；本次新增适配器不修改网页生成流程。

## 教材功能精简（当前版本）

已按用户要求删除教务网教材目录读取、教材站点搜索下载、来源配置及其连接器实现；同步工具已从 MCP 工具清单移除。已有本地教材与个人数据不作删除，保留上传、离线查看、教材版本关联和习题正文提取。历史自动教材同步任务不能再重试；遗留排队任务会以功能已移除结束，不访问外部网站。

复习卷的出卷备注上方新增提示：若作业仅有教材上序号，请在备注中上传题目照片或教材电子版。此处为提示文字，不代表增加了图片识别能力。

本地教材、插件及连接器回归通过，网页教材测试与生产构建通过。全音频重新识别、扫描教材 OCR、板书 OCR 仍未完成。

## 上传 GitHub

### 同日启动器补丁（startup-fix）

修复重复启动时仅更换端口、却争用同一个学校登录浏览器配置的问题。采用用户数据目录中的操作系统文件锁；已有同目录服务就绪时复用原网页，不创建第二套连接器。第二个窗口退出只关闭自身，不停止原服务；进程异常退出后锁自动释放。不同项目目录或缺少所选平台时给出明确提示，避免误用服务。

启动器回归 10 项通过。重新启动两个连接器后，学在浙大登录检查为 ok，课程接口返回 20 条且无错误；重复启动验证成功复用原端口。智云连接器进程就绪，但本次智云平台连接检查为 network_error，未宣称其同步恢复。

该启动修复已包含在最新 `local-textbooks` 包中，上传时使用这一批新包。EXE 继续读取相邻 tools/dev.py，无需单独替换或重建 EXE。

1. 用 source ZIP 对应的源码目录内容作为仓库根目录。README.md、plugin.json、.mcp.json.example、plugins、apps、connectors、packages、contracts、tools、docs/release 等一起上传。不要直接把整个个人 D:/ai 目录上传。
2. Windows ZIP 作为 GitHub Release 附件。里面的 EXE 必须与源码目录一起解压，不是完全免安装的单文件软件；首次需安装 Python、Node/npm 与依赖。
3. PACKAGE-MANIFEST.json 提供逐文件 SHA256；PACKAGE-AUDIT.json 记录排除和已知本地值扫描结果。校验文件不包含个人数据。
4. 项目尚未指定开源许可证。不要误认为上传仓库就自动获得某一种开源许可。

## 文件大小与作业详情补读

设置页新增“文件大小”，独立配置平台下载、本地上传、文档解析；默认分别为 1024 / 1024 / 256 MiB。设置保存在本机用户数据目录，API 与连接器下一次操作读取。已有进程须重新启动以载入新代码；设置更新本身不要求重启。

连接器支持仅传递本机暂存句柄，后端分块复制并核对 SHA256、大小和格式，避免大文件经 Base64 跨进程传递。超过下载上限不再在 API 中标为权限不足，超过解析上限的文件已保存在本地，可提高上限后重新解析。解析器仍有页数、片段数、时限及压缩包解压限制；并未实现无限制解析或视频重新转写。

学在浙大作业列表正文为空时补读已记录的 GET /api/activities/{id} 活动详情；详情暂时失败保留既有正文，返回单项错误。数理方法第二/第三次作业的本地记录确实无正文和附件，实际学校页面本次因桌面工具无法确认网址而未能检查；不能宣称这两次作业题目已恢复。需重启后重新同步验证，如内容仅为图片还需要 OCR 或用户补充可读题干。

相关后端和连接器回归 123 项通过（另 7 个子测试）；文件设置页面测试与上传检查测试通过，网页生产构建通过。

## 作业 PDF 附件同步修复

作业不再只同步说明文字：列表/活动详情中的 uploads 附件会作为可下载资源入库，并按平台资源外部 ID 关联回所属作业。多份附件独立处理，重复同步保持同一关联；缺失/异常字段保留原有关联，不把其他课程的资源接入当前作业。包含附件的作业生成一次作业任务，附件不另生成阅读任务。

出卷时，仅有已解析 PDF 附件、没有网页文字说明的作业也可作为材料；不再额外报“作业无正文”。附件不可读、待解析或未勾选时仍明确显示缺口。

已通过正式启动器保留的登录，实际同步数理方法课程。原先缺失的两次作业各读到一个 PDF，约 65 / 103 KiB；第一份作业的 PDF 也补齐。三份附件均已下载和解析为 ready，第二/第三次作业的真实材料读取结果为两份附件、0 个缺失项。本轮未调用模型生成新卷。PDF 的图形、复杂公式与版式仍遵循原有解析局限，应按原文核对。

相关后端、连接器、出卷和任务生成测试 365 项通过，另 7 个子测试通过，网页生产构建通过。最新导出包使用 homework-pdf 后缀，已包含此前文件大小设置与启动器修复。
