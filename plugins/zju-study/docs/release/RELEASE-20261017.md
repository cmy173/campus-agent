# 2026-10-17 复习卷数学公式修复

复习卷原先在网页和 HTML 导出中直接显示纯文本；提示词允许不带数学定界符的 LaTeX，Markdown 导出也未规范化，导致公式显示为源代码。

页面的题干、选项、答案、解析与评分点改用本地 Markdown + KaTeX 渲染，打印页共用组件。显示层兼容 $...$、$$...$$、\(...\)、\[...\]、数学代码块及旧卷中可明确识别的裸数学表达式，不改写已保存试卷。普通代码保留，原始 HTML 不执行，LaTeX 信任命令关闭。

Markdown 导出统一数学标记，独立公式脱离题目标题和代码块。Markdown 阅读器仍须支持数学扩展。学生版、答案版 HTML 内嵌 KaTeX、woff2 字体及其许可证，可断网打开和打印，不加载 CDN。后台需要初始化网页依赖以提供导出所需资源。

后续出卷与修复提示词要求使用标准数学标记及正确 JSON 转义，并更新提示词版本。此项修复只处理显示和导出，不替模型纠正题意，也不恢复 PDF 提取中丢失的公式。

验证：前端 16 项、后端与提示词/校验回归 77 项通过，生产构建通过。对已有数理方法卷，浏览器页面 24 处公式、离线答案版 HTML 75 处公式均无 KaTeX 错误。正式启动器已重启，Markdown、学生版 HTML、答案版 HTML 三个真实导出请求均返回 200。本轮没有重新调用模型出卷。

最新包名为 zju-study-plugin-0.3.0-alpha.1-20261017-math，已包括此前启动器、大小设置和 PDF 作业附件修复。源码包用于仓库根目录，Windows ZIP 作为 Release 附件。个人试卷、截图与数据库不纳入发布包。
