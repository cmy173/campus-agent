## §7 逐项结论

| # | 提议 | 结论 | 落点与备注 |
|---|---|---|---|
| 1 | 平台代码 `xzzd`/`zykt` 登记 | 接受 | 冻结于契约。新增平台走变更流程（CHANGELOG + 版本号） |
| 2 | Capabilities.features 三态 | 接受 | `capabilities.schema.json`；`status: supported/unsupported/unknown/preview_only`；未实测必须 `unknown`（留 note 说明证据） |
| 3 | SyncResult 信封 | 接受 | `sync-result.schema.json`；`errors` 用完整 Error（含 request_id）；补充必填 `mode: incremental/resync`（呼应 A4 游标失效全量对照）；B 侧幂等键建议 `(platform, course_id, cursor.previous)` |
| 4 | 删除语义条款 | 接受 | 已写入 README 与 schema 描述：「空响应与失败不产生删除；仅 `reason=explicit_delete_signal` 是删除事件」；deletions[].reason 为封闭枚举 |
| 5 | ConnectionState 与恢复动作 | 接受 | `connection-state.schema.json`；`RecoveryAction {type: user_login, entry_url, message}`。注意：B 侧 Connection 资源另有 `disabled`（用户停用），不在 A 的 state 枚举内 |
| 6 | fetch handle/denial 双分支 | 接受 | `fetch-outcome.schema.json`；`status: ok/denied/gone/transient_error`；`handle.kind=local_file`（ref 为一次性受控定位，绝不入 API）；`denial.reason: preview_only/permission_denied/copyright_restricted` |
| 7 | 错误码表 | **按修改接受** | AUTH_EXPIRED 可重试修正为 **false**（对齐 A4「登录失效不重试不循环」），恢复路径随 `details.action` 下发；README 错误码表拆为 API 层与适配器/任务层两张；UPSTREAM_CHANGED（能力置 unknown + 降级）、PARSE_FAILED 收录 |
| 8 | Resource 扩展字段 | **按重命名接受** | `bytes→size_bytes`、`media_type→mime_type`、平台侧 `updated_at→source_updated_at`（避免与记录自身 updated_at 混淆）；`access_level` 原样；**`parse_status` 不进适配器 upsert 载荷**（B/D 侧字段，入库后由 B 置 pending）；另增 `extent_value/extent_unit`（可选，page/slide，供 D 估算时长） |
| 9 | Recording 扩展字段 | **按修改接受** | `subtitle_languages` 原样（BCP-47；空数组=确认无字幕，`null`=未知）；`transcript_status` 枚举合并：`none` 并入 `unavailable`，保留 `unknown`，新增 `processing`（服务端生成中）与 `failed`（获取失败），最终 `pending/processing/ready/unavailable/unknown/failed`；新增 `transcript_next_check_at` |
| 10 | 映射候选结构 | **结构接受、API 推迟 v0.2** | `mapping-candidate.schema.json` 冻结；字段重命名 `a/b_course_id→left/right_course_id`（与左右方向解耦）；v0.1 走人工确认 `POST /courses/{id}/source-refs`，自动建议端点 v0.2 |
| 11 | 游标不透明约定 | 接受 | README 约定 7 + 所有 schema 字段描述；样例 `cur_x9f3a7b21` 可用 |
| 12 | content_hash 格式与可空 | 接受 | `common.schema.json#/$defs/content_hash`：`^sha256:[0-9a-f]{64}$` 或 `null` |
