# CR007：个人使用闭环收尾

用户授权：修复交接说明及代码中的瑕疵并完成收尾。此记录说明实际实施的接口变化，不要求额外审批。

- Connection / ConnectionState 增加 `unsupported`、`service_unavailable`，区分未接入、本地服务缺失、平台阻断；老客户端需升级枚举。
- 增加 GET `/connections/{connection_id}/courses` 和 POST `/connections/{connection_id}/courses/import`，读取平台课程并原子建课挂接；平台列表 ID 在导入前是平台 ID，入库后才分配内部 ID。
- 增加 GET `/recordings/{recording_id}/transcript`，按需获取智云已有字幕；空列表不代表解析成功或永久无字幕。
- ZIP 容器保留 `skipped`，支持成员独立入库解析；损坏、越界、加密或超限容器明确失败。替代 CR006 的“所有 ZIP 永远不解包”策略。
- 系统推断耗时随资料解析结果刷新；用户编辑耗时标记 `fact_source=user` 并保留。
- 同步通过本地桥接获取受控附件，自动解析并派发任务生成；会话物料仍不进入 API。
- 网页默认 real，测试显式 mock；个人启动器只补平台连接，使用独立 personal 数据库，不 seed。

JSON schema、OpenAPI 与前端枚举同步更新；验证证据见 `docs/coord/10-收尾修复与使用说明.md`。
