# CR011：V2 通用运行时与设置

日期：2026-10-13。状态：merged（本地实施，无远端推送）。

依据用户确认的 V2 执行合同，取消仅校园工具限制，复用 Harness 的通用工具与官方 provider。保留原有校园参数验证和服务端会话配置。

兼容新增：

- GET /agent/settings、PUT /agent/settings：个人任务目录、技能目录、独立搜索配置、MCP 服务配置。用于本机单人产品。普通设置可读取；密钥不回传，MCP 环境变量/请求头以保留标记显示，真实值由本地加密存储保存。
- POST /agent/settings/mcp/{server_name}/test：实际 MCP 连接与工具发现，不调用会话模型。
- POST /agent/settings/search/test：实际上游搜索 provider 的一次公开搜索连通性测试，不发送本地资料；费用提示显示在测试按钮旁。
- POST /agent/internal/model-lease：官方 provider 调用前验证会话配置并预留模型预算，不返回凭据。
- internal/model 接受实际运行时工具注册表，可选 tools 保留旧调用行为。已知校园 schema 不允许替换；通用和 MCP 工具由 Harness 注册。max_tokens 默认16384、上限65536。
- Agent 事件兼容新增 harness_event（上游会话工具/助手事件，含 session_id）及 subagent.started/finished。旧 tool_result 信封保留，前端去重后分别展示领域来源与通用结果。

契约由 tools/export_agent_contract.py 从实际 FastAPI Agent 路由及引用 schema 生成；原公开学习接口保持不变。真实官方服务、持续任务和浏览器仍有未完成验收，详见唯一进度文档。
