# CR012：统一运行预算与子任务控制

日期：2026-10-14。状态：merged（本地实施，无远端推送）。依据用户已确认的 V2 执行合同。

兼容新增：

- POST /agent/internal/tool-lease：本轮通用工具预算预留，按 session/call ID 幂等；校园工具保持原领域缓存计数，两者共用预算。
- POST /agent/internal/model-error：官方 provider 归一化错误记录，不接受远端原始正文。
- POST /agent/internal/control-address：自有 SDK 注册 loopback 子任务控制地址与本轮授权，地址不回传浏览器。
- POST /agent/turns/{turn_id}/subagents/{child_id}/interrupt：本机会话所有者停止指定子任务；返回接受状态，实际终态来自 Harness 事件，重复停止已结束任务幂等。
- 事件新增 subagent.stop_requested，并转发上游 subagent/catalog 以展示任务名称。原 started/finished 保持兼容；aborted 显示已停止，不等同于运行失败。

使用公开 agents/subagents 服务，未修改上游私有实现。独立前台/continuable 并行控制、API 集成与浏览器验证通过；跨轮后台任务及重启恢复仍未完成。契约由 tools/export_agent_contract.py 导出。
