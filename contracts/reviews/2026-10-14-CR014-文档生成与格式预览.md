# CR014：文档生成与格式预览

日期：2026-10-14。状态：merged（本地实施，无远端推送）。依据用户的 C 档文件与文档产物合同。

- 文件 preview 接口声明按 kind 区分的正式响应模型，增加 spreadsheet 类型（工作表/行数组、截断标记、has_formulas）。严格封闭旧预览类型枚举的客户端需升级；原内容下载接口仍可使用。数值、零、布尔值、空值和日期/时间保留含义，公式原文明确展示。
- 预览限制最多8张表、每表100行24列、单元格2000字符；触及范围或内容截断均明确标记。较大工作簿保留下载路径，损坏文件返回 FILE_PREVIEW_FAILED，下载仍保留原始内容。
- 新 document-artifacts 技能和脚本通过通用工具运行，未新增 Agent 主循环或依赖 Codex Runtime。生成 Markdown/PDF/Excel 后仍使用既有 publish_file 事件/接口交付。
- PDF 预览由按需加载的 PDF.js6.4.299 实现，支持翻页/放大/取消旧页渲染及销毁加载任务；预览优先展示。
- 实际生产运行发现旧 Ant Design/rc/style 手工拆包在初始化时产生未定义函数，UI 依赖归入同一 vendor chunk，PDF 模块/worker保持独立按需加载。记录实际生产浏览器重验结果，不把成功构建当作运行证据。

契约由 tools/export_agent_contract.py 导出：22路径、24引用schema。真实 DeepSeek 试用及持续任务/浏览器/校园迁移等 Goal 条件继续推进。
