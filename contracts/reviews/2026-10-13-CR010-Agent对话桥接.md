# CR010：本地 Agent 对话与内部工具桥接

- 日期：2026-10-13。
- 类型：兼容新增；既有 v0.2 路径和响应保持不变。
- 状态：merged（已补录接口；整体 M1 验收仍未完成）。
- 依据：用户授权按首轮执行合同实施对话核心；历史 A/B/C/D 审核角色不作为本轮另行委派要求。

新增路径独立记录在 `contracts/openapi/agent-openapi.yaml`，原路径与新增路径的并集必须与 FastAPI 逐项相等。新增会话创建/列表/恢复、幂等发送、轮次/事件读取、取消，以及内部 schemas/tool/model POST。

当前仅支持本机单人数据库。浏览器 cookie 隔离对话记录，不宣称旧业务 API 已具备多租户鉴权。服务端从本机课程与连接计算允许范围；每轮 Node SDK 使用随机能力令牌，服务端只保存其 hash，结束、取消、重启时失效。密钥只由 Python 从原密钥存储读取，不传给 Node、工具或网页。

每个会话绑定用户确认的模型配置快照；配置变化时拒绝发送。新 journal 独立于学习数据库，不运行学生数据迁移。重启将未结束轮次标记 interrupted 并保留已记录事实，不自动重放业务写入。

桌面前端、M2 计划授权、后台 job 闭环及完整接线仍须后续实施与验收；这些新增端点本身不能证明整体验收完成。
